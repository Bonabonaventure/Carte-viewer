Carte Viewer

Prêt. La carte choisie reste locale au navigateur.
Mode d’emploi
1. Ouvrez cette page une première fois avec Internet.
2. Autorisez la localisation quand le navigateur la demande.
3. Choisissez votre fichier carte HTML local.
4. Après mise en cache, ce visualiseur peut se rouvrir hors connexion.

Le fichier sélectionné est lu localement par JavaScript. Il n’est pas téléversé par ce visualiseur.
